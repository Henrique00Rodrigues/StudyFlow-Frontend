Classes do Bootstrap:

top-50:
O elemento fica a 50% da altura do elemento pai.
Ela posiciona o canto superior do elemento no meio do container, não o elemento inteiro.

start-50:
Posiciona o elemento na metade da largura do pai.

translate-middle:
Ela move o elemento:
50% da sua própria largura para a esquerda
50% da sua própria altura para cima
Geralmente é usada junto com top-50 e start-50.

overflow-auto:
Controla o comportamento quando o conteúdo é maior que o espaço disponível.
Isso significa:
Mostra barra de rolagem somente quando necessário.
Se o conteúdo couber, nenhuma barra aparece.

#Javascript:
O trim() não remove os espaços entre as palavras. Ele só remove os espaços do final e início. Ex: " Banco de Dados " para "Banco de Dados". Ele não faz " Banco de Dados " para "BancodeDados".
